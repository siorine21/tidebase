## 2. 詳細機能要件

### 2.1 釣果記録機能（F-01）

#### 入力フロー（5 ステップウィザード）

```
先頭ボタン：[🎣 釣果を記録] または [😞 ボウズで記録]

STEP 1：魚種・サイズ・匹数
  └ 魚種サジェスト（初期 13 種）
  └ サイズ入力 → 出世魚自動判定（提案表示）
  └ 数量メモ（任意・フリーテキスト）
  └ 匹数（デフォルト 1）

STEP 2：タックル・ルアー（ボウズ時スキップ）
  └ ルアーレシピ選択（お気に入り順・最近使用順）
  └ ヒットレンジ（表層/中層/底層/ボトム直撃）
  └ ロッド・リール・ライン・リーダー

STEP 3：スポット
  └ 地図から選択 or 現在地から近いスポットを提案

STEP 4：写真（任意）
  └ S3 アップロード

STEP 5：メモ
  └ 潮汐・天気は自動取得して保存
  └ 公開範囲（グループ / 自分のみ）
```

#### ボウズ記録

- フォーム先頭に「😞 ボウズで記録」ボタンを配置
- STEP 1（魚種・サイズ）と STEP 2（タックル・ルアー）をスキップ
- `is_skunked = TRUE`、`count = 0` で保存
- 釣果一覧で「😞 ボウズ」として表示

### 2.2 潮汐・天気情報機能（F-02）

#### ホーム画面の表示内容

- 今日の釣行スコア（/5）：潮汐種別・天気・風速から Python で算出
- 24 時間潮汐グラフ（満潮・干潮の時刻をグラフ内に表示）
- 0 時から 3 時間単位・24 時間後まで天気横スクロール
  - 朝マズメ（6 時）・夕マズメ（18 時）をハイライト表示
  - 各カード：時刻・天気アイコン・気温・風向風速
- 直近釣果 2 件

#### 潮汐詳細画面（SCR-003）

- 地点切替タブ（お気に入り地点、HTMX 部分更新）
- 今日のサマリ：潮汐種別・釣行スコア・満潮/干潮時刻
- 大型 24 時間潮汐グラフ（満潮・干潮ラベルをグラフ内に表示）
- 0 時から 3 時間単位・24 時間後まで天気横スクロール
- 週間カレンダー（潮汐種別色分け：大潮=赤・中潮=オレンジ・小潮=青）

#### 釣行スコア算出ロジック（5 段階）

| スコア | 条件 |
|-------|------|
| 5 / 5 | 大潮 + 晴れ or 曇り + 風速 5m 以下 |
| 4 / 5 | 中潮 + 晴れ or 曇り + 風速 7m 以下 |
| 3 / 5 | 小潮 or 長潮 + 風速 10m 以下 |
| 2 / 5 | 悪天候（雨）or 強風（10m 超） |
| 1 / 5 | 嵐・台風レベル |

### 2.3 スポット管理機能（F-03）

#### スポット登録フィールド

| フィールド | 型 | 必須 | 説明 |
|----------|---|------|------|
| スポット名 | TEXT | ✅ | |
| 座標（緯度・経度） | POINT | ✅ | 地図タップまたは現在地から取得 |
| フィールド種別 | ENUM | ✅ | サーフ / 磯 / 港湾 / 管理釣り場 / 河川 |
| 対象魚種 | TEXT[] | 任意 | |
| 公開範囲 | ENUM | ✅ | `group`（デフォルト）/ `private`（Phase 5〜） |
| 干潮時のみアクセス可 | BOOLEAN | 任意 | ON 時は⚠️マーカーを表示 |
| 水深 | DECIMAL | 任意 | m 単位 |
| 底質 | TEXT | 任意 | 砂地・岩礁・砂利 等 |
| アクセスメモ | TEXT | 任意 | 駐車場・徒歩時間・注意事項 |
| ポイントメモ | TEXT | 任意 | 離岸流・ブレイク・渡磯タイミング等 |
| 最寄り潮汐観測点 | TEXT | 自動 | 座標から自動選択 |

#### マップ上のピン色分け

| フィールド種別 | ピン色 |
|-------------|-------|
| サーフ | 青（`#4A9ECC`） |
| 磯 | 緑（`#4CAF50`） |
| 管理釣り場 | 緑（`#4CAF50`） |
| 港湾 | カラシ（`#C9A84C`） |

### 2.4 ルアーレシピ機能（F-04）

- 22 種のルアー種別（詳細は確定仕様書参照）
- フィルタ：ジグ / ミノー / シンペン / バイブ / クランク / スプーン / エギ / ワーム / その他 / ⭐お気に入り
- 実績スコアバー：紐付いた釣果件数を自動集計して表示
- 釣果入力（SCR-002）から直接参照・選択可能

### 2.5 グループ機能（F-05）

- グループ作成・参加（URL シェア方式のみ）
- グループフィード：公開範囲「グループ」の釣果が自動掲載
- コメント機能（HTMX でリアルタイム部分更新）
- グループは複数作成可（家族グループ / 仲間グループ 等）

### 2.6 ローテーションログ機能（F-06）

管理釣り場スポット選択時のみナビゲーションに「ログ」タブが表示される。

```
現在使用中セクション：
  └ ルアー名・レンジ・経過時間
  └ 反応ボタン：[🎣 HIT] [👀 チェイス] [😐 無反応] [💔 バラシ]

タイムライン：
  └ 時刻・ルアー・反応タグ・詳細メモ
  └ ボーダー色：HIT=緑・チェイス=オレンジ・無反応=グレー・バラシ=赤

操作：
  └ 「切替」ボタン → レシピ一覧 → 選択で切替時刻を自動記録
  └ HIT タップ → 釣果入力フォーム呼び出し（ルアー情報は自動引継ぎ）
```

## 3. 非機能要件

### 3.1 パフォーマンス

| 指標 | 目標値 |
|------|--------|
| 初期表示（3G 回線） | 3 秒以内 |
| API レスポンス | 500ms 以内（P95） |
| 画像アップロード | 5MB 以下の写真を 3 秒以内 |

### 3.2 セキュリティ

| 要件 | 実装方法 |
|------|---------|
| 認証 | Supabase Auth（JWT） |
| データアクセス制御 | Supabase RLS（Row Level Security） |
| シークレット管理 | AWS SSM Parameter Store（本番）/ .env（開発） |
| HTTPS | CloudFront + ACM（無料 SSL 証明書） |
| S3 バケット | パブリックアクセス無効・署名付き URL でアクセス |

### 3.3 可用性

- AWS Lambda：自動スケーリング・マルチ AZ
- Supabase Free：99.9% SLA（無料プラン）
- CloudFront：グローバル CDN によるキャッシュ

## 4. 画面遷移フロー

```
ホーム（SCR-001）
  ├─ FAB（＋）→ 釣果入力（SCR-002）
  │     ├─ ルアー選択 → レシピ一覧（SCR-008）
  │     ├─ スポット選択 → マップ（SCR-004）
  │     └─ 登録完了 → 釣果一覧（SCR-006）
  ├─ 潮汐グラフタップ → 潮汐詳細（SCR-003）
  └─ 直近釣果タップ → 釣果一覧（SCR-006）

マップ（SCR-004）
  └─ スライドアップ → スポット詳細（SCR-005）
        ├─ 潮汐確認 → 潮汐詳細（SCR-003）
        └─ 釣果フィルタ → 釣果一覧（SCR-006）

ローテーションログ（SCR-010）
  ├─ ルアー切替 → レシピ一覧（SCR-008）
  └─ HIT タップ → 釣果入力（SCR-002）
```
